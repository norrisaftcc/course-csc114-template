# 07 — Your Product — Discovery and Design

**Loop 2 · Sprint 4 Begin · Weeks 13–14 · 150 pts.** Role: Product Owner. Every
planning skill reapplied to the student's own product; ends with a pitch before any build.

## ⬡ Before Class — Async

> **NTS New Office.** New badge. New office. New product. The lobby resets — but the
> student knows how it works now.
> *"3 minutes to pitch your product to the board. They've heard 47 pitches today. What
> makes yours worth funding?"*

- Q Problem Framing Quiz — 5 descriptions, identify which have defined problem/user/solution · *MLO 7.1 · Canvas New Quiz*
- ▶ User Persona Builder — select components for 3 users, useful vs. decorative · *MLO 7.2 · Sim*
- ▶ MVP Scope Activity — from 20 features, select the 5-7 true MVP · *MLO 7.1/7.3 · Sim*
- ▶ Product Pitch Structure — drag sections in professional order, best hook + CTA · *MLO 7.5 · Sim*
- ▶ Feedback Integration — given pitch feedback, decide incorporate/defer/out-of-scope · *MLO 7.6 · Sim*

**Lucidchart (ERD + wireframes require instructor review before M8 build):**
- ◈ Power-Interest Grid — own product stakeholders
- ◈ User Story Map — own product backlog by journey
- ◈ ERD — own product schema · *🔒 gates M8 build*
- ◈ Wireframes — 3+ screens · *🔒 gates M8 build*
- ◈ System Architecture — components, connections, data flow

## ⬡ In Class — Facilitated

- 🎤 **Product Concept Pitches — Whole Class** — 5-min structured pitch per student.
  Norris and peers give real-time glows/grows. Review group peer forms due within 48
  hrs. Pitch slots assigned in Module 6.
- 🗣 **MVP Scope Negotiation** — After pitches, Norris challenges MVP choices. Students
  must defend scope or revise. Encourages scope discipline before building begins.

**⚡ RSI Touchpoint (×2):** 1. Written approval on product brief before design activities
unlock. 2. Instructor comments in Lucidchart ERD + wireframes before Module 8 build
begins. *Response window: 72 hrs · Platform: Canvas Comment + Lucidchart · 🔒 ERD/wireframe review gates M8.*

### MLOs

- **7.1** Identify real-world problem suitable for IS solution · *Analyze · CLO 2*
- **7.3** Produce 15+ story backlog with criteria, points, MoSCoW · *Create · CLO 2*
- **7.4** Create design package: ERD, wireframes, use case · *Create · CLO 3*
- **7.5** Deliver 5-min product pitch to class · *Apply · CLO 5*
- **7.6** Incorporate pitch feedback into revised brief · *Apply · CLO 5*

## ⬡ After Class — Canvas Submissions

- **Own Product Brief** — problem, target user, MVP scope, success criteria, tech stack with justification · *30 pts · Rubric · 🔒 Approval gates design*
- **Own Product Stakeholder Profiles** — 3+ personas; Lucidchart power-interest grid; differentiated comms strategy · *25 pts · Rubric · CLO 2*
- **Own Product Backlog** — 15+ user stories with format, testable criteria, story points, MoSCoW; story map alongside · *35 pts · Rubric · CLO 2*
- **Own Product Design Package** — ERD, wireframes (3+), use case, system architecture, design rationale (300 words) · *35 pts · Rubric · CLO 3*
- **Product Concept Pitch** — 5-min; peer glows/grows from review group within 48 hrs · *25 pts · Presentation · CLO 5*
- **Revised Product Brief** — updated post-pitch; notes what changed/why and what wasn't incorporated/why · *0 pts · Completion · 🔒 Gates M8*

## Thread & gates

- **Own Product Thread:** Every planning skill from M1-6 reapplied to student's own
  product. Module ends with pitch before any building begins. ↳ *Deliverable: Brief +
  stakeholders + backlog + design + pitch.*
- **Unlocks when:** M6 retrospective submitted. **Product brief approval gates design.**
  **Design review gates M8:** ERD + wireframe comments required. **Gates M8 on:** Revised brief submitted.
