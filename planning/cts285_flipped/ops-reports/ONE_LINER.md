# One-Liner — Module 4.5: Teach Your Agent The Flow

**Headline:** Delegate the Sacred Flow's mechanics to a coding agent — keep the merge, and the judgment, human.

**What / Why / Proof**
- **What:** A coding agent (Claude Code baseline; Codex CLI + Gemini CLI) opens the Issue and PR via `gh`+`git`; the student reviews and merges.
- **Why:** As stakes rise toward Module 8, the Flow should get cheaper, not heavier — and the student practices customer judgment on AI-drafted requirements.
- **Proof:** 3 self-graded deliverables — Flow write-up + merge screenshot, a filled agent corpus, and a customer self-assessment. 50 pts · self-graded (awarded by default on completion).

**Elevator pitch:** Students hand the boring git ceremony to an AI, stay the one who merges, and use that same agent to start speccing the product they'll build in the capstone.
